# Handoff: v2.1 layout pass — everything above the fold

Layout-only pass over all tabs of the shipped v2.0 dashboard. **No new data, no new collection, no visual-language change** — same cockpit tokens, same components, rearranged so each tab reads as a control panel at 1440×900.

**Visual reference:** `reference/Dashboard v2.1 - Above the Fold.dc.html`. Open it in a browser and click the tabs inside the frame. The dashed amber line is the 900px fold; every tab's primary content sits above it. Read spacing and colour from it; don't lift its markup (inline-styled for the design tool).

Build against `system/cockpit.css` classes. Where this spec names a size, it's the reference value.

---

## Global

### Header → one row, 54px

Today: header row + a second status row + a tab row, ~110px before any content.

New: a single 54px bar — logo (28px) · `PLANET EXPRESS` + `casalan.com · ship computer` · **tabs inline** · spacer · `pipeline idle · scanned 4m ago` · `SCAN ✈` · `LOG OUT`.

- Tabs are 32px tall, Chakra Petch 600 12px. Active = cyan tint + `#35c5d8` border; inactive = transparent border, `--pe-ink-dim`.
- Drop the second status row (`PIPELINE IDLE · SENSORS NOMINAL`) and the right-edge `last scan` timestamp — both collapse into the one status line.
- Drop the sparkline from the header; it duplicates the System tile.

### Tabs

`Overview · Backups · Network · Actions · History · Chat · Config · Crew` — **Crew is new** (see below).

### Remove the right sidebar from every tab

Ship's Computer + Crew currently occupy a ~150px column on Overview, Backups and Network. Remove it everywhere. Farnsworth keeps **one line** on Overview; the rest moves to the Crew tab.

### Page padding

`main` padding `14px 18px 18px`, 12px gap between rows. Panels 12px radius, `13px 14px` padding.
