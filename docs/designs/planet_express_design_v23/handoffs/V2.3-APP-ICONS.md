# V2.3 · App icons (selfh.st)

> **Shipped as v2.3.0. Where this handoff and the code disagree, the code wins.** Two decisions
> below were reverted during the build. Do not re-introduce them from this text.
> - **PNG only, never SVG.** An SVG served from the dashboard's authenticated origin can carry
>   `<script>`: a compromised upstream icon becomes a same-origin scripting surface. Source icons
>   are 512px and the largest render is 40px, so SVG buys nothing. `planet_express/core/iconcache.py`
>   checks PNG magic bytes (`PNG_MAGIC`, `:35`, enforced at `:245` with the size cap) and rejects
>   everything else; magic bytes are trusted over `Content-Type`.
> - **`planetexpress.icon` takes a slug, never a URL.** A URL in a label makes the dashboard fetch
>   whatever a compose file names (SSRF) and bypasses the pinned CDN. A label may choose among what the
>   code sanctions, never point at something new (same rule as widget labels, option A, 2026-09-27).
>   `planet_express/core/icons.py:60` `slug_for()` accepts only a constrained slug; an unusable slug
>   falls back to the image-name match.

Builds on V2.2. Everything in V2.2 stands; this adds app icons wherever a container is named.
Reference: `reference/Dashboard v2.3 - App Icons.dc.html` (section E + drawer, detail, widgets, network pills).

## Source
- selfh.st icons: https://selfh.st/icons/ · repo `selfhst/icons`.
- Fetch URL: `https://cdn.jsdelivr.net/gh/selfhst/icons/png/<slug>.png` **PNG only.** Never fetch `/svg/` or `/webp/`.
- Some icons have a `<slug>-light` variant. On our dark surfaces, use `-light` when it exists for icons that are dark or monochrome by default.

## Matching
1. `planetexpress.icon` label on the container (a **slug only**, never a URL) wins.
2. Otherwise, the image name with registry, owner and tag stripped: `lscr.io/linuxserver/sonarr:4.0.9` → `sonarr`.
3. Alias map for mismatches, e.g. `adguardhome` → `adguard-home`, `qbittorrent-nox` → `qbittorrent`.
4. No match → two-letter monogram tile.

## Delivery
- The backend fetches each icon once, caches it to disk (`data/icons/<slug>.<ext>`), and serves it from `/icons/<slug>`. The browser never calls the CDN.
- Missing results are cached for 24h, so misses aren't re-fetched on every scan.
- A 404 goes to the monogram. It is never shown as an error.

## Rendering
- Sizes: 13px router pills · 18px widget headers · 28px drawer rows · 40px detail header (36 on mobile).
- Tile: #101b2c fill, 1px #1c2c44 border, radius 7 (28px) / 10 (40px), icon inset ~14%. Pills and widget headers use the bare icon, with no tile.
- Health: a 9–10px LED on the tile's bottom-right corner, with a 2px ring in the surface colour. Icon colours are never tinted.
- Down: the icon drops to 40% opacity and the row goes red as before.
- Monogram: Chakra Petch 700, #5f7391, in the same tile.
- Overview stack tiles keep status dots only.
